# Contributing

Corrections are the most valuable contribution: a wrong citation, a missed amendment, an effective date, a state
law we do not list yet.

1. Open an issue titled with the requirement `id` (or the state, for a missing law).
2. Link the **primary source**: the statute, regulation, session law or official agency guidance. Secondary sources
   (law-firm alerts, news) are welcome as pointers but cannot be the only source.
3. Say what should change and from which date.

The files in `data/` are generated from Checkbox's catalog, so pull requests that edit them directly are applied to
the catalog by a maintainer and come back with the next version; you are credited in the commit. We review reports
within a week. Accepted changes are listed in the changelog at https://checkbox.site/changelog.
